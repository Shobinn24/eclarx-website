Using the app.

Everything from your first CSV audit to publishing the storefront badge.

1 · Audit from a CSV

Export reviews from your review platform (Loox, Judge.me, Yotpo, and most others offer CSV export), then upload it on the Audit page and click Run audit. The file needs at minimum:

  • An email column — header containing "email".
  • A product column — a product URL or handle; headers like "product url" or "product handle" are detected automatically.
  • Optional: rating and review date columns. Dates enable purchase-timing checks; ratings enable the rating-gap analysis.

No export handy? The app can build a sample CSV from your own store's orders so you can see the full flow first.

2 · Connect Loox

  1. In Loox: Settings → API. Copy the public store ID and the API secret key.
  2. In TallySeal Reviews Audit: Review sources → Connect Loox, paste both, connect.
  3. Back on the Audit page, run an audit from Loox — no export needed.

3 · Connect Judge.me

  1. In Judge.me: Settings → Integrations → API. Copy the private API token (the server-side token, not the public one).
  2. In TallySeal Reviews Audit: Review sources → Connect Judge.me, paste the token, connect.

Credentials are encrypted before storage and only ever used to read reviews. Disconnect anytime from the same page.

4 · Reading your results

Each audit reports four verdict counts (matched, likely match, customer with a different product, no matching order), your overall verified match rate, the rating gap between matched and unmatched reviews, and a per-product breakdown. Audits are saved to history; only the aggregates are stored.

5 · Publish the storefront badge (Pro)

  1. Run an audit you are happy with, then click Publish in the Storefront badge section. Set a display threshold if you only want the badge shown above a certain match rate.
  2. In Online Store → Customize, open the template where you want the badge (product pages, footer, or announcement area) and add the Audited badge app block.
  3. Save. The badge shows your published match rate, review count, and audit date — nothing else, and it never updates without you republishing.
